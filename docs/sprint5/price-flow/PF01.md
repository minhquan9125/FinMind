## PF01: normalize_activity

`normalize_activity(envelope, *, symbol, source_name, now, session_status) -> dict` in backend/src/market_data/activity.py. Envelope has fetched_at timezone-aware ISO string and rows list with exactly one matching symbol (other symbols in a batch allowed, duplicate target rejected). session_status is one of intraday/after_close/unknown/closed. closed rejects; unknown is accepted as intraday pending with warning. now must be timezone-aware datetime. Normalize stock symbol uppercase with regex [A-Z]{3}, reject malformed input. Quote exchange must be HOSE/HNX/UPCOM. TD is exact dd/mm/YYYY, <= fetched_at's Vietnam date, fetched_at <= now+30s; historical replay is allowed. Require valid positive finite OHLC prices and OHLC relations; pre-open all-zero quote rejected. volume_accumulated is an exact nonnegative int <=2^63-1 (no bool). Foreign buy/sell volumes optional same type; never coerce missing to0. Money optional nonnegative finite Decimal from str/int/Decimal, no bool/float, bounded numeric(24,4). Missing is None, empty/non-finite/negative supplied values reject. total_value maps to total_value_vnd; foreign buy/sell value are None for this KBS adapter because no verified fields. volume_basis/value_basis unknown; no inferred money. source_updated_at=None (unverified source time), fetched_at aware datetime, trade_date date; symbol/source_name/exchange strings; observation_status intraday/after_close, quality_status always pending_reconciliation, warnings list. Unknown fields ignored, no count/ownership fields treated as money. Normalizer never declares validated. Return no net field (calculator derives net).

Unit reference: publisher labels total_value VND at https://vnstocks.com/docs/vnstock/vnstock-data-v3/cau-truc-du-lieu/market ; matched/put-through scope remains unknown for installed KBS4.0.9 response.
